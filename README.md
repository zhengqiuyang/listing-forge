# listing-forge · 跨境电商全链路运营 Agent 🛠️
[![CI](https://github.com/zhengqiuyang/listing-forge/actions/workflows/ci.yml/badge.svg)](https://github.com/zhengqiuyang/listing-forge/actions/workflows/ci.yml) [![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](./LICENSE)

> 从选品到上架的执行链：市场信号 → 选品分析 → 多平台 listing 生成
> （Amazon / Shopify / TikTok Shop 各自格式与 SEO）→ 评论洞察 → 调价建议。
> 不是又一个"AI 文案工具"——是一条能连续执行、每步可回溯的 agent 链路。
