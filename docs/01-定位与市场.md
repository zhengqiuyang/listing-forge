# 01 · 定位与市场 【提案】

## 一句话定位

**中小跨境卖家的运营执行链**：把"看十个工具、做一堆表"压缩成一条
"选品→上架→洞察→调价"的可回溯 agent 流水线。

## 市场判断

- 跨境卖家是 AI 工具付费意愿最强的群体之一（工具 ROI 当场可算：一个 listing 的
  A/B 差异就是真金白银）；行业惯例定价 $50-300/月，支付无教育成本；
- 现有工具格局是"单点辅助"海：关键词工具、文案生成、评论分析各卖各的；
  **"多步连续执行 + 全链路数据留痕"的 agent 形态仍是空档**；
- 国内做出海卖家工具的额外便利：人民币收款、中文支持、卖家社群（知无不言等）直达。

## 用户分层

| 层 | 用户 | 场景 | 备注 |
|---|---|---|---|
| P0 | 精铺/精品中小卖家（1-10 人，Amazon+TikTok Shop 双平台） | 每周上新 5-20 SKU | 最痛、最愿为自动化付费 |
| P1 | 工厂型转型卖家 | 旺季节点上架冲刺 | 客单价高，决策慢 |
| P2 | 代运营公司 | 多客户多店铺批量 | v1 的 API 化客群 |

## 竞品格局（2026-10）

| 竞品 | 形态 | 弱点（=空档） |
|---|---|---|
| Helium 10 / Jungle Scout（老牌套件） | 关键词+选品+listing 工具箱，加 AI 文案 | 工具箱形态：数据给你、活还是你干；贵（$39-229/月） |
| 国内卖家工具（领星、店小秘等 ERP 系） | ERP+基础 AI | 重订单/库存管理，运营智能是配菜 |
| 各类 AI listing 生成器（独立产品/插件，2024-2026 大量涌现） | 单点文案 | 生成完就结束，无市场数据回路、无多平台格式深度 |
| 卖家自用 ChatGPT 工作流 | prompt+表格 | 无平台 API 直连、无留痕、不可回溯 |

**切入逻辑**：不打数据牌（Helium 10 的数据壁垒打不动），打**执行牌**——
用卖家自己的账号数据（授权 API）+ 公开信号，跑完整链路并留痕。
链路价值 > 单点数据价值。

## 定价（提案）

| 档 | 价格 | 内容 |
|---|---|---|
| 免费 | 1 条链路/月 | 完整体验一次选品→上架 |
| 专业版 | $49/月 | 30 条链路 + 双平台 + 评论洞察 |
| 团队版 | $149/月 | 不限量 + 多店铺 + 团队协作 + API |

锚定 Helium 10 中档，功能面讲"执行 vs 工具箱"的差异故事。

## 分发

1. 知无不言论坛 + 卖家微信群：案例帖（"一条链路 40 分钟从信号到上架"全程录屏）；
2. 与 clauselens 共享跨境客群（合规合同审查是卖家的相邻痛点）；
3. 服务商渠道：代运营公司贴牌（P2 客群反哺）。

## kill 准则

- 6 周内 <10 个卖家真实跑通 ≥2 条链路 → 冻结；
- 12 周内 <3 个付费 → 冻结；链路编排层经验回流 saas-starter。
