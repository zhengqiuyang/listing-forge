# 04 · 生产计划与风险 【提案】

## 里程碑（Wave 3，共 10 周；前置：SP-API 账号已就位，saas-starter 已复用）

| 周 | 交付 | 验收 |
|---|---|---|
| W1-2 | 连接器层：Shopify（最简授权）→ TikTok Shop → SP-API | 三平台授权+读取打通 |
| W3 | 编排层（DAG+检查点+重跑） | 演示链路可中断续跑 |
| W4-5 | ② 选品评分卡 + ③ listing 生成（三平台） | 评测集合规率/语域指标达门槛 |
| W6 | 闸门服务 + 上架 dry-run→真实发布 | 全链人工审批流走通 |
| W7 | ④ 评论洞察 + ⑤ 建议工单 | 归因一致率 ≥0.75 |
| W8 | 留痕时间线 UI + 团队版 | 卖家试点 3 家开跑 |
| W9 | 试点迭代（真实店铺上 10 个真实 SKU） | 试点卖家留存使用 |
| W10 | 支付 + 案例 content | v0.1 发布 |

## 风险登记表

| 风险 | 概率 | 影响 | 对冲 |
|---|---|---|---|
| SP-API 审核不过/超期 | 中 | 高 | 前置数周办理（roadmap 已列）；先用 Shopify+TikTok 交付，Amazon 后补 |
| 卖家账号因第三方工具被平台风控 | 低 | 极高 | 全合规 API（绝无爬虫/自动化浏览器灰色路径）+ 写操作闸门；这个纪律写进 README 公示 |
| 平台 API 政策变动 | 中 | 中 | 连接器隔离层吸收变化；多平台布局本身就是对冲 |
| listing 生成同质化（AI 味重） | 中 | 中 | 语域评测集硬门槛 + 卖家自有语料 few-shot |
| 卖家教育成本（不懂 agent/链路） | 中 | 中 | UI 隐去术语：只呈现"时间线+确认按钮"；案例视频营销 |
| Helium 10 们加"执行链"功能 | 中 | 中 | 中小卖家价格带 + 中文服务 + 链路留痕差异化；kill 准则兜底 |

## kill 准则执行细则

冻结时回收：连接器层（三平台适配是硬资产，可独立开源或并入任何电商后续项目）；
编排层回 saas-starter；评测集独立开源。
